# Contributing to OpenMicBoard

Contributions are welcome. Please open an issue before large changes so the problem and proposed direction can be discussed.

## Development

- Target Windows 11 24H2 or later and test the architecture you change when practical.
- Keep audio routing local and preserve the opt-in nature of any network behavior.
- Add or update focused tests for behavior changes.
- Do not add a dependency, telemetry, or external service without clear justification and documentation.

## Pull requests

Keep pull requests small, describe user-visible changes, state how you tested them, and call out privacy, security, or compatibility effects. Avoid including personal paths, user names, tokens, recordings, or proprietary media in commits, logs, screenshots, and issues.

By contributing, you agree that your contribution is provided under GPL-3.0-only.
