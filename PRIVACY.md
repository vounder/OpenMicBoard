# Privacy Policy

OpenMicBoard is a local-first soundboard. Its normal operation processes audio on the device and stores board configuration and managed audio locally.

It does not require an account, telemetry service, advertising identifier, or cloud upload. OpenMicBoard does not transmit your clips, board data, audio, device names, or hotkeys as part of normal operation.

The application may offer opt-in update checks. If enabled, the update request necessarily contacts the configured update source and can expose ordinary network metadata to that service, such as IP address and request time. Disable update checks to keep OpenMicBoard offline.

Managed imports are copied into the private library under opaque names; their original source paths are not retained for those managed assets. Linked imports retain their selected file path locally so the application can find the file. Delete a linked tile or change it to a managed import if that local reference is not desired.

This policy describes OpenMicBoard itself. Virtual audio drivers and communication applications are separate products governed by their own policies.
