# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the project maintainers through the repository's private security-reporting channel when one is available. Do not include exploit details in a public issue until a fix or coordinated disclosure plan exists.

Include the affected version, Windows version and architecture, reproduction steps, impact, and any safe proof of concept. Reports are acknowledged as capacity permits.

## Scope

Security reports are welcome for OpenMicBoard source, release artifacts, local data handling, audio routing, and build dependencies. Third-party virtual audio drivers and communication applications must be reported to their respective vendors.

## Safe use

Install audio drivers only from trusted publishers. Treat unsigned OpenMicBoard builds as untrusted until you have verified their origin or built them yourself.
